describe your boss in exactly one word.

## Entry

**Meetingfluencer** — 15 characters.

The boss who treats every meeting like a stage and every calendar invite
like a content drop: always presenting, rarely deciding, somehow in five
meetings at once.

## How to run

```sh
python3 main.py
```

`main.py` (Python standard library only) reads `entry.txt` next to it,
validates the competition gate (UTF-8, 1–30 characters, not only
whitespace, a single word with no spaces), and writes the word to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Deterministic:
repeated runs produce byte-identical output.
